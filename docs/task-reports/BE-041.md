## Changes
- Allow only `http`/`https`; reject metadata hostnames (`metadata.google.internal`, `localhost`)
- Reject RFC1918, loopback, link-local (`169.254/16`), CGNAT, ULA, AWS IMDS IPv6, IPv4-mapped blocked addresses
- Re-validate every resolved A/AAAA and every redirect Location hop
- Caps: max redirects 3, max body 5 MiB, timeout 15s (env-overridable)
- DNS-rebinding mitigation: connect to resolved IP with `Host`/`servername`
- No third-party packages added
