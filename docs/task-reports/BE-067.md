# Task BE-067 — Accept batched offline events

## Summary
Added `POST /api/v1/sync/events` to drain client offline outbox batches of `playback_state` and `favorite` writes, with a 100-event size cap and per-event `clientEventId` idempotency via the existing single-write use cases.
