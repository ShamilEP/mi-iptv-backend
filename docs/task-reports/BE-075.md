## Changes
- `POST /api/v1/devices/register` (`tv`|`companion`, platform, optional push token)
- `GET /api/v1/devices` lists non-revoked devices
- `DELETE /api/v1/devices/{id}` soft-unlinks and clears push token
- `POST /api/v1/devices/{id}/heartbeat` updates `last_seen_at`
- API returns `pushTokenConfigured` only (never raw token)
