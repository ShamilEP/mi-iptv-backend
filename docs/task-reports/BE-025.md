# Task BE-025 — Implement POST /auth/logout and revocation

## Summary
Implemented `POST /api/v1/auth/logout` to deny-list the current access JWT (`jwt:deny:{jti}`), revoke device refresh tokens, and optionally close all account sessions (`allSessions` + account epoch + `logout_all` refresh revocation).

## Changes
- Device logout: Redis jti deny-list + refresh revoke reason `logout`
- Account logout: `jwt:acct-epoch:{accountId}` + revoke all refresh tokens (`logout_all`)
- Bearer (or body) access token; response `{ status, scope }`
- In-memory Redis when `REDIS_URL` unset
