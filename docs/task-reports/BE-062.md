# Task BE-062 — Implement GET /sync/state?since=

## Summary
Implemented `GET /api/v1/sync/state` delta pull for playback states, favorites, and sources using account `change_seq` cursors (ADR-005/009), with deletion tombstones, pagination, and `409` when the cursor is behind `tombstoneFloor`. Numeric `since` is accepted only as a deprecated alias for `cursor` (not wall-clock time).

## Changes
- Unified delta stream ordered by `change_seq` with `limit` / `nextCursor` / `truncated`
- Soft-deletes returned as `deleted: true` (favorites + sources; playback when tombstoned)
- Source payloads never include credentials/ciphertext
- Tombstone floor → `SYNC_FULL_RESYNC_REQUIRED` (HTTP 409)
