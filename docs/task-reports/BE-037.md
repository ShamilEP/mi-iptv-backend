# Task BE-037 — Implement kid profiles and parental PIN

## Summary
Adds hashed parental PIN storage (Argon2id via `hashOpaque`), a throttled verify endpoint, and profile content restrictions by rating/source when metadata exists (FR-023). Public APIs expose `pinConfigured` only — never the hash or clear PIN.

## Changes
- Persist parental PIN as Argon2id PHC (`pin_hash`); clear PIN never stored or returned
- `PUT /api/v1/profiles/{id}/pin`, `POST .../verify-pin` (Redis `rl:pin:{accountId}:{profileId}`, 5 fails / 900s → 429), `PATCH .../restrictions`
- Restrictions: `kidMode`, `maxRating`, `allowedSourceIds`, `blockedSourceIds`; evaluation fails open when rating/source metadata is absent
- `PasswordHasher.hashOpaque` so short numeric PINs bypass account password policy
