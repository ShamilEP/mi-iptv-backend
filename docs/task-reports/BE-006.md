## Changes
- Default `/api/v1` routes require Bearer JWT; health and auth register/login/refresh are public
- Gateway sets `request.accountId` / `request.auth` from verified claims (no longer trusts `x-account-id` alone at the server edge)
- Validation: `application/json` Content-Type when a body is present; max JSON body bytes
- Rate limit: per access-token `jti` (else hashed IP); `/health` skipped for ALB probes
- Reused `AssertAccessTokenActive` for signature + deny-list checks
