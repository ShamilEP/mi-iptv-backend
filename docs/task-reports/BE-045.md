# Task BE-045 — Build the Xtream Codes adapter

## Summary
Implemented an Xtream Codes `player_api` adapter that authenticates, fetches live/VOD/series categories and listings, builds playable stream URLs, and fails closed on expired or blocked accounts. All outbound calls go through SSRF-safe `FetchSourceUrlSafely` (BE-041). No new npm packages.

## Changes
- Authenticate via `player_api.php` (`user_info.auth/status/exp_date`)
- Fetch live, VOD, and series categories + listings
- Build stream URLs (`/live|movie|series/{user}/{pass}/{id}.{ext}`) — never logged
- Map Expired → `XTREAM_ACCOUNT_EXPIRED`, Banned/Blocked/Disabled → `XTREAM_ACCOUNT_BLOCKED`, auth≠1 → `XTREAM_AUTH_FAILED`
