# Task BE-044 — Build the M3U adapter

## Summary
Implemented a streaming M3U playlist adapter that extracts `#EXTINF` IPTV attributes, tolerates encodings and malformed lines, and runs in an isolated worker thread with strict time, heap, byte, and entry limits. No new npm packages.

## Changes
- Streaming `#EXTINF` → entry mapping with required IPTV attributes
- Encoding: UTF-8 BOM, UTF-16 LE/BE BOM, latin1 fallback
- Malformed rows skipped (orphan URI, missing URI, `file:` schemes)
- Caps: maxBytes 20 MiB, maxEntries 100k, maxLineLength 16 KiB, timeout 30s, worker old-gen 64 MB
- Isolation via `worker_threads` + `resourceLimits` + terminate-on-timeout
