# Task BE-060 — Build the sync domain module

## Summary
Added a framework-free `src/domain/sync` module covering sync versions, playback/favorites conflict rules (LWW, 60s max-position, `forceReset`), and `clientEventId` idempotency, aligned with Backend §3.1 / ADR-005 and the SQL helpers in `001_postgres_schema.sql`. Exhaustive unit tests cover the decision tree.

## Changes
- `syncVersion` helpers: non-negative integer, initial `1`, increment on accept
- Playback: optimistic match accepts (incl. rewind); within 60s + other device + lower position → `max_position` reject; else LWW; `forceReset` wins
- Favorites: always accept; base mismatch → `lww`
- Idempotency: prior `clientEventId` returns original outcome without re-applying writes
- No persistence/HTTP wiring (later sync service tasks)
